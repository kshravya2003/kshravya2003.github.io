01 / MACHINE LEARNING
6DIMENSIONS

How much of an image
can six numbers hold?

Image Captioning

PyTorch · ResNet-18 · GRU · Flickr8k

Exploring a six-dimensional information bottleneck between visual features and language, across four preprocessing methods.

A team course project comparing raw, Gaussian, Sobel, and hybrid image preprocessing. A frozen ResNet-18 produces features; a compact bottleneck and GRU generate captions. The notebook includes BLEU/METEOR evaluation and noise experiments.

Explore the notebook & report

Wumpus World

Python · Genetic Algorithms · Simulation

Evolving action sequences for a grid-world agent navigating hazards and searching for gold.

Includes an environment, agent, genetic algorithm, step-by-step simulation, multi-configuration evaluation, CSV outputs, and plotting. Experiments are stochastic and results vary between runs.
